## Observation

Across the Bruce Untitled Text, Pistis Sophia, and Books of Jeu, sacred carriers repeatedly behave less like passive symbols and more like access-control tokens.

Generic architecture:

IDENTITY / STATE
-> TOKEN (name, word, seal, sign, formula)
-> PRESENT / UTTER TOKEN AT BOUNDARY
-> GUARDIAN OR BOUNDARY RECOGNIZES TOKEN
-> BEHAVIOR CHANGES
-> PASSAGE / REVELATION / ASCENT

## Computer-science analogy

This resembles authentication/authorization more closely than substitution:

- identity claim
- credential/token
- verifier/guardian
- protected boundary/resource
- accept/reject behavior
- state transition after authorization

The analogy is heuristic only. It is not a claim that ancient authors conceived computer security.
