# Candidate v17 — Local Phonetic Transition Operator

Status: CANDIDATE AFTER X25–32 INTERNAL TEST

## Core model

Marsanes does not use performance vocabulary throughout its phonological taxonomy.

Instead, the secure performance bundle is localized at X30:

BEAT + PITCH + SILENCE + ATTACK/ONSET
-> SUMMON SEMIVOWELS
-> ORDER / SUBJECT
-> ONE SOUND.

## Contrast

X31:
vowel-consonant strings are generated explicitly
without
beat / pitch / silence / horme.

Therefore performance is not required for all combination.

## Candidate function

PERFORMANCE marks a SPECIAL PHONETIC TRANSITION.

Possible triggers:
- crossing letter-class boundaries;
- activating semivowels;
- interacting with hidden/unrepresented sound entities;
- collapsing plurality into one sound.

## Current safest formulation

PERFORMANCE is a LOCAL TRANSITION OPERATOR,
not a universal sacred-token metadata layer.

## Prediction for next test

Compare X30 and X31 at the level of operation type.

If performance is tied specifically to:
SEMIVOWEL ACTIVATION
or
MANY->ONE SOUND UNIFICATION,

then ordinary CV-generation passages should systematically lack the bundle.

## Falsifier

Downgrade if:
- another secure X25–32 passage uses the same performance terms without a transition/unification function;
- X30's one-sound clause proves syntactically independent of the performance phrase;
- direct facsimile invalidates the relevant visible/restored relations.
