# Candidate v15 — Local Execution Binding Model

Status: CANDIDATE AFTER v14 NEGATIVE GENERALIZATION TEST

## What v14 changed

The project previously entertained:

SACRED TOKEN = FORM + EXECUTION PROFILE

as a general cross-token abstraction.

v14 did not support the predictive version of that claim.

## Revised model

FORM
+ LOCAL TEXTUAL / PROCEDURAL BINDING
+ EXECUTION PARAMETERS
-> LOCAL EFFECT.

Execution parameters can be operative without constituting a universal metadata layer.

## Supported components

1. Exact same sacred forms can appear under different executions.
2. Some of those differences coincide with different effects.
3. Ancient procedures explicitly prescribe repetition, direction, gesture, silence, breath, pitch, and other execution variables.
4. Stable same-form/same-execution/same-function cases also exist.

## Unsupported generalization

Do not infer:

EXECUTION PROFILE -> FUNCTION

across tokens without local textual evidence.

Do not infer:
- pitch means one ontological level globally;
- silence means one class globally;
- repetition count identifies one deity globally;
- one execution vector functions as a universal credential.

## Marsanes consequence

B4 should be modeled locally:

ALTERED CONSONANTAL FORM
+ PERFORMANCE{BEAT, PITCH, SILENCE, ATTACK/ONSET}
-> LOCAL HIDDEN-POWER RELATION

The direction and exact mechanism remain unresolved.

## Falsifiable next step

Collate Codex X page 30 directly against the critical edition and translations.

If the local syntax shows that performance terms directly determine the relation to hidden gods/powers, Local Execution Binding strengthens.

If the terms belong only to grammatical description with no ritual relation, downgrade the ritual-performance interpretation.
