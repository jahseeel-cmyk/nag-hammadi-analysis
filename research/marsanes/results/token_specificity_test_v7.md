## Main Marsanes result

Configuration identity is not carried primarily by vowel identity alone.

It is distributed across:
- identity,
- repetition,
- position/order.

The full written feature set perfectly distinguishes the normalized C1/C2/C3 local-unit dataset.
The simplified sound-collapsed feature set loses one distinction and falls to 94.74%.

This directly strengthens the earlier model:

CONFIGURATION > SIMPLE SUBSTITUTION.

It is compatible with a token-specificity system because token identity can be generated by a combination of symbol + operator + position.

It does NOT prove these forms were credentials at cosmic gates.

## Capacity comparison — exploratory only

Hekhalot coded gate entropy:
2.565448372 bits.

A seven-way written Marsanes vowel inventory has maximum single-symbol capacity:
log2(7) = 2.807354922 bits.

The simplified five-sound collapse has:
log2(5) = 2.321928095 bits.

Therefore:
- seven distinct written categories are sufficient in principle to label six gate states uniquely;
- five collapsed sound categories are not sufficient if one uses only one symbol per state.

This is a capacity analogy, NOT a historical mapping between Marsanes vowels and Hekhalot gates.

Do not claim:
A=gate 1, E=gate 2, etc.
