Date opened: 2026-09-19

## Integrity note

Allogenes was preregistered after Grammar v4 was frozen.

## Upward / return path

Allogenes explicitly describes:
- being taken by eternal Light out of the garment;
- being taken up to a holy place;
- approaching the Aeon of Barbelo;
- withdrawing to Vitality;
- withdrawing to Existence;
- receiving revelation of the Unknown One;
- stilling oneself in silence.

Conservative upward coding:

Embodied state
-> holy place / Barbelo
-> Vitality
-> Existence
-> Unknown One

This satisfies the v4 requirement for an upward/return transduction chain.

## Downward / manifestation path

Allogenes also describes:
- the Universal / Invisible source as that from which the others were emitted;
- First Thought as the medium through which the incomprehensible source is apprehended;
- the source as conferring Being / Existence;
- participation in first Vitality;
- knowledge and salvation flowing through the resulting structure.

Conservative manifestation coding:

Universal / Unknown Source
-> First Thought
-> Being / Existence
-> first Vitality
-> knowledge / salvation

This is an emanational/ontological manifestation path, not a narrated descent journey.

## Homologous states

The same ontological states occur on both sides of the model:

- Existence
- Vitality

Upward:
Allogenes withdraws to Vitality and then to Existence.

Downward:
the source confers Being / Existence and the resulting activity participates first Vitality.

This is the strongest new structural result in this test.

## Sacred-language / epistemic mediation

The text repeatedly ties:
- revelation,
- instruction,
- silence,
- hearing,
- knowledge,
- Word,
- praise,
- and the uttered formula "zza zza zza"

to the process of divine apprehension.

A particularly important passage describes a power as:
- at rest and silent,
- yet uttering the sound "zza zza zza".

This is highly relevant to the project because it places silence and articulated sound in the same operative metaphysical frame.

## Important caution

The result does NOT mean Allogenes narrates a literal descent through the exact reverse sequence.

The downward side is ontological/emanational:
source -> First Thought -> Existence -> Vitality.

The upward side is experiential/noetic:
embodied seer -> holy place -> Vitality -> Existence -> Unknown One.

Therefore the correct claim is:

The same ontological states participate in both manifestation and return.

That is stronger and more defensible than claiming exact mirrored travel.
