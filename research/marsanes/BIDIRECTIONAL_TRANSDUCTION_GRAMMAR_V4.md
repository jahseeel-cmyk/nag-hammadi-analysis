## Central hypothesis EH005

Sacred-language transduction is potentially bidirectional:
- outward/downward: hidden source -> differentiated expression -> manifestation/knowledge-bearing form;
- inward/upward: ritual articulation/knowledge -> silence or boundary transition -> ascent/return.

This is a structural hypothesis, not a claim that every text contains both directions.

## State classes

B0 HIDDEN_SOURCE
ineffable / invisible / pre-existent / silent source.

B1 MEDIATED_EXPRESSION
thought / voice / name / command / word / sacred formula / invocation / blessing.

B2 DISCLOSED_OR_PARTICIPATED_STATE
revelation / seeing / knowledge / empowered form / divine participation.

B3 RITUAL_BOUNDARY
silence / stripping / baptismal or noetic transition / explicit threshold.

B4 ASCENT_RETURN
ascent / return / restoration to higher source.

B5 DESCENT_MANIFESTATION
descent / coming forth / manifestation / propagation into lower level.

## Primary bidirectionality criterion

STRONG BIDIRECTIONAL MATCH requires:
1. at least one explicit upward/return path;
2. at least one explicit downward/manifestation path;
3. at least one homologous state, realm, or ordered level appears in both directions;
4. at least one direction is mediated by B1 sacred expression or B3 boundary;
5. no new operator is required.

## Partial criterion

PARTIAL:
- both upward and downward movement exist but no homologous state can be established; OR
- only one direction has a complete sacred-language transduction chain.

## Failure

NO_BIDIRECTIONAL_SUPPORT:
- only one directional movement is present, or
- both directions are generic travel with no sacred-language/epistemic mechanism.

FAIL_MODEL:
- a necessary mechanism requires an operator not frozen above.

## Anti-hindsight rules

- Do not reinterpret every descent as manifestation.
- Do not count static divine hierarchy as movement.
- Do not count numerical symmetry as reversal.
- Do not infer reverse-path identity unless the text explicitly links the levels or path.
