## Translation history

### Pearson / 1981 critical edition

The older edition renders the passage approximately:

changed consonants
-> "submit" to the hidden gods
-> by means of beat, pitch, silence, impulse.

Its editorial note, however, says the passage implies that the adept who chants correctly can bring gods and angels into subjection.

That already reveals the core ambiguity:
surface translation sounds passive,
editorial interpretation sounds active.

### Turner / later critical-edition lineage

Turner's scholar translation gives:

consonants are independent/diverse
-> they prefix and suffix the hidden gods.

Then a NEW clause:

by means of beat, pitch, silence, and attack
-> they summon the semivowels
-> which are subjected to one sound.

This later reading changes the architecture substantially.

## Lexical audit of hypotassein

Coptic Dictionary Online for ϩⲩⲡⲟⲧⲁⲥⲥⲉ includes all of the following senses:

- be obedient / submit;
- be placed under;
- subject / subdue;
- place something under the rule of another;
- be suffixed, of words;
- be suffixed with object relationships involving sound/word.

This is decisive for interpretation.

The technical linguistic "suffix/order" reading is lexically real.
It is not an ad hoc modern rescue.

At the same time, active "subject/subdue" is also lexically possible.

Therefore the verb by itself cannot settle ritual agency.

## Performance terms

### Silence
ⲕⲁⲣⲱϥ
Secure lexical meaning:
SILENCE.

### hormē
ϩⲟⲣⲙⲏ / Greek ὁρμή

Attested semantic range includes:
- impulse;
- onset/movement;
- vigor;
- cue/timing.

Turner's "attack" is therefore plausible as a performance-onset gloss.

Safe operational gloss:
ATTACK / ONSET / IMPULSE.

### Pitch
ⲙⲛⲧⲟⲩⲁϩⲉⲓⲏⲧ

Pearson's critical note relates this to Greek πικρότης / τὸ πικρόν and musical "sharpness/pitch."

Safe gloss:
PITCH / TONAL SHARPNESS.

### Beat
The critical edition glosses the first performance term as musical beat/ictus.

This term is less lexically transparent in isolation than karof or hormē, so confidence should remain slightly lower.

Safe gloss:
RHYTHMIC BEAT / ICTUS.

## The crucial syntactic result

The biggest correction is not the meaning of hypotassein.

It is WHERE THE PERFORMANCE PHRASE ATTACHES.

The Coptic order is:

HIDDEN GODS :
BY MEANS OF beat + pitch + silence + hormē :
THEY SUMMON THE SEMIVOWELS
ALL OF WHICH ARE SUBJECTED TO ONE SOUND.

Turner's later translation therefore has a strong syntactic basis for forward attachment:

PERFORMANCE BUNDLE
-> SUMMON SEMIVOWELS
-> SUBORDINATE / UNIFY THEM TO ONE SOUND.

The older Pearson translation attaches the same instrumental phrase backward:

PERFORMANCE BUNDLE
-> SUBMIT / SUBJECT RELATION TO HIDDEN GODS.

Both have appeared in scholarship, but the later forward attachment better matches:
- clause ordering;
- punctuation/separation in the transcription;
- the immediately following semivowel clause;
- Turner's later grammatical reading.

## Revised B4

Retire the old single-chain B4:

ALTERED CONSONANTS
+ PERFORMANCE
-> HIDDEN-GOD SUBMISSION.

Replace it with TWO linked relations.

### B4-A — hidden-god attachment/order

ALTERED / DIVERSE CONSONANTAL FORMS
-> HYPOTASSEIN RELATION
-> HIDDEN GODS.

Best strict gloss:
PREFIX / SUFFIX / ORDER / ATTACH.

Alternative:
SUBJECT / SUBMIT.

Agency:
UNRESOLVED.

Restoration sensitivity:
MODERATE, because the first member of the paired construction is restored.

### B4-B — performance-driven phonetic unification

PERFORMANCE{
  BEAT,
  PITCH,
  SILENCE,
  ATTACK/ONSET
}
-> SUMMON SEMIVOWELS
-> SUBJECT / ORDER THEM
-> ONE SOUND.

Status:
STRONGLY SUPPORTED.

Restoration sensitivity:
LOW.

This is now the strongest local reading.

## Main discovery

The performance bundle may not primarily encode control over hidden gods.

It may describe HOW phonetic elements are activated and brought into a unified sounded form.

That is a materially different model.

Instead of:

PERFORMANCE -> COSMIC CONTROL

the text more securely supports:

PERFORMANCE -> PHONETIC ACTIVATION / INTEGRATION -> ONE SOUND.

This fits the surrounding section's concern with:
- consonants;
- vowels;
- semivowels;
- syllabic combinations;
- nomenclature;
- sound classes.

## Relationship to sacred language

This does NOT make the passage non-esoteric.

The surrounding text explicitly binds the phonological system to:
- angelic nomenclature;
- soul configurations;
- hidden gods/powers.

Recent scholarship likewise treats Marsanes as theorizing the mechanics of sacred/angelic naming and voces magicae.

The best synthesis is therefore:

GRAMMATICAL-PHONOLOGICAL MECHANISM
embedded inside
SACRED / ANGELIC NOMENCLATURE.

## v15 update

Local Execution Binding survives, but it becomes more precise:

FORMAL CLASS
-> ATTACHMENT / ORDERING
-> PERFORMANCE-DRIVEN SOUND REALIZATION
-> SACRED NOMENCLATURE / LOCAL EFFECT.

Performance is not a universal cross-token code.

Within Marsanes, however, performance appears to be part of the process by which formal letter categories become operative sound.

## Strongest current formulation

MARSANES IS BEST MODELED AS A SACRALIZED PHONOLOGICAL GRAMMAR.

It uses ordinary Greek grammatical categories,
but binds them to:
- soul-structure;
- angelic nomenclature;
- divine/hidden powers;
- controlled performance.

The esoteric content lies in the BINDING and USE of the grammar,
not in the bare grammatical categories themselves.
