# Candidate v16 — Performance-Driven Phonetic Unification

Status: CANDIDATE

## Core claim

In Marsanes X 30:15–22, the strongest local syntax is:

PERFORMANCE PROFILE
-> SUMMON SEMIVOWELS
-> ORDER / SUBJECT THEM
-> ONE SOUND.

## Performance profile

- beat / ictus
- pitch / tonal sharpness
- silence
- attack / onset / impulse

## Separate hidden-god relation

The immediately preceding clause is retained separately:

ALTERED / DIVERSE CONSONANTS
-> HYPOTASSEIN
-> HIDDEN GODS

with hypotassein interpreted conservatively as:

ATTACH / ORDER / PREFIX-SUFFIX

while:
SUBJECT / SUBMIT
remains a live secondary possibility.

## Why this is stronger than v11-v15

Earlier models bundled the performance terms directly with hidden-god control.

The line-by-line collation shows that the performance phrase can attach more naturally to the following "summon the semivowels" clause.

That reduces metaphysical overreach and increases philological precision.

## Sacred-language interpretation

The model remains esoteric because the phonological mechanism is textually embedded in:
- angelic nomenclature;
- soul configurations;
- hidden powers.

The grammar is ordinary in substrate but sacralized in function.

## Prediction

Within X 25–32:
performance vocabulary should occur preferentially at transitions from
LETTER CLASSIFICATION
to
SOUNDED / COMBINATORY REALIZATION.

It should be absent or reduced in purely taxonomic descriptions.

## Falsifier

Downgrade if:
- direct facsimile shows critical restoration/punctuation is wrong;
- performance phrase cannot syntactically govern semivowel summoning;
- neighboring taxonomy uses identical performance terms without sound-generation function;
- the one-sound clause is unrelated to the performance list in the critical syntax.
