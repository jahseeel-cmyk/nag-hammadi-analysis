# Source-Order PGM Expansion Batch v13

Date: 2026-09-20

## Sampling rule applied

The preregistered PGM expansion rule requires source-order selection rather than interest-based selection.

This batch scans the early PGM sequence and records the first 20 procedure/stage units for which the accessible source evidence supplies at least one non-generic execution constraint that can be coded under the frozen v13 feature schema.

Known v12 anchor passages already present in the pilot (PGM IV.475-829, PGM V.1-53, PGM VII.756-794) were not duplicated.

## Important exclusions

Generic "say/recite this prayer" alone was NOT enough to qualify.

A row required at least one of:
- directional projection;
- body/gesture coupling;
- prescribed silence;
- explicit repetition count;
- nonlexical sound/timbre;
- volume/intensity.

Where only a secondary paraphrase was accessible, the row is marked SCHOLARLY_PARAPHRASE and will be excluded from the strict primary-only sensitivity analysis.

## Result

20 new source-order procedure/stage rows.

This raises the working v13 dataset from 59 to 79 rows once merged.

The target remains n >= 120 before any preregistered hypothesis decision.

## Method warning

The current source acquisition environment could not use Scite because the monthly MCP allowance is exhausted until 2026-10-01 UTC.

Therefore this batch uses:
- Betz translation mirrors,
- searchable book/PDF excerpts,
- peer-reviewed/open scholarly discussions,
with provenance recorded row-by-row.

No v13 hypothesis threshold was changed.
