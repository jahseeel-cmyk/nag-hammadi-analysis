# Performance-Carrier Grammar v11 — Candidate

## Core formula

TOKEN = WRITTEN FORM + PERFORMANCE.

Where PERFORMANCE may include:
- rhythmic ictus;
- pitch;
- silence/rest;
- attack/onset.

## Marsanes anchor

X 30:12-18 binds altered consonantal forms and hidden powers through an execution bundle.

## Important correction

The model does NOT require deciding whether the hidden powers:
- dominate the sounds,
- are dominated by the sounds,
- or are grammatically ordered with the sounds.

The invariant claim is narrower:

THE RELATION DEPENDS ON PERFORMANCE PARAMETERS.

## Candidate architecture

CLASS
-> FORMAL TRANSFORMATION
-> GENERATED FORM
-> PERFORMANCE PARAMETERS
-> HIDDEN-POWER RELATION
-> RITUAL / ONTOLOGICAL EFFECT

## Strong esoteric reading

A sacred token may not be fully specified by its spelling.

Its identity/function may depend on how it is executed.

This would explain why:
- grapheme distinctions matter;
- performance terms matter;
- silence can itself be an operator;
- fixed names/forms may require exact ritual realization.

## Falsifier

Downgrade this model if:
- critical facsimile/edition removes the performance bundle;
- performance terms prove non-vocal/non-musical;
- comparable school exercises use the same terms with no ritual function;
- external ritual corpora show no execution-sensitive token behavior.
