## Core structural operators

OP1 SERIES(V): ordered traversal of a defined vowel inventory.

OP2 REPEAT(X,n): repeat a single symbol or grouped unit n times, where n is measured from the text and carries no symbolic meaning by assumption.

OP3 GROUP(sequence): preserve explicit grouping boundaries.

OP4 COMBINE(C,V): combine consonantal and vocal elements into syllabic/name forms.

OP5 SUBSTITUTE_VOWEL(frame,V): retain a consonantal frame while substituting vowel identity. Restricted to restoration-sensitive analysis until manuscript security improves.

OP6 CONCATENATE(X,Y,...): join simple units into compound vocal/name sequences.

## What counts as a count-function match

A primary count-function match requires all of the following:

1. a repeated vocal/symbolic unit X^n with n >= 2;
2. n is recoverable without silently restoring missing tokens;
3. an independently stated cardinal/ordinal/fold count occurs in the same syntactic sentence or clause;
4. the stated count is explicitly attached to the divine/ritual/ontological entity or operation in that same unit;
5. n equals that independently stated count.

Secondary audit window:
- +/- 3 manuscript lines.
- Secondary-window matches are recorded but do NOT count as primary prediction success.

## Null model for count-function alignment

If at least 4 independently scorable repeated units exist:
- preserve the observed repeat counts;

- compare the observed exact-match count with the permutation distribution.

If fewer than 4 units exist, no inferential p-value is reported. Use descriptive counts only.

## Frozen decision rule

- INSUFFICIENT_DATA: fewer than 2 independently scorable repeated vocal units.
- FAIL_FROZEN_GRAMMAR: a necessary new structural operator is required.
- NO_SUPPORT_FOR_COUNT_PARAMETER: at least 2 units, zero primary exact count-function matches.

- STRONG_DIRECTIONAL_SUPPORT: at least 2 primary exact count-function matches, no new operator required.
- STATISTICAL_SUPPORT: STRONG_DIRECTIONAL_SUPPORT plus permutation-tail p <= 0.05 when the sample-size rule permits.
