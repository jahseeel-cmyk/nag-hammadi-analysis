# v14 Line-by-Line Source Audit — Strongest A/B Families

Date: 2026-09-21

## Audit rule

No family is accepted merely because the same divine name appears in two texts.

A high-bar A/B case requires:
1. exact normalized token identity;
2. source-locatable occurrences;
3. explicitly different execution/deployment profile;
4. explicitly different ritual stage, function, or effect;
5. no speculative spelling-family merge.

## F01 — Diadem-of-Moses full name sequence

### PGM VII.619-627

The Betz/O'Neil translation prints one continuous name sequence and immediately assigns it two uses:
- recitation on rising, before speaking to anyone -> invisibility;
- utterance of the same names over drinking cups given to a woman -> erotic attraction.

This is the cleanest direct A/B case in the dataset.

Status:
QUALIFIES.

Caution:
the second instruction reuses the preceding names anaphorically rather than reprinting the entire sequence.

Web cross-checks:
- Betz translation mirror, Yumpu PGM VII.619-627
- Hermetic Library, Ecloga Liber III

## F02 — ABRASAX

### PGM VII.201-202
ABRASAX is written on scarlet parchment and applied as a migraine plaster.

### PGM LXIX.1-3
A strength formula including ABRASAX is spoken seven times while the practitioner holds both thumbs.

### PGM LXXIX.1-7 / LXXX.1-5
The ABRASAX/MICHAEL anger-restraint charm is spoken three times; Betz notes LXXIX and LXXX preserve the same text in different scribal witnesses.

This gives:
same exact token
+ graphic vs sevenfold+gesture vs threefold vocal deployment
+ different explicit effects.

Status:
QUALIFIES STRONGLY.

It also contains an internal null:
LXXIX and LXXX preserve same token + same execution + same function.

## F04 — IAO

### PGM V.24-30
IAO receives an explicit performance instruction: it is projected toward earth, air, and heaven within an oracle procedure.

### PGM VII.619-627
IAO occurs inside the Diadem sequence used for invisibility.

### PGM VII.969-972
IAO occurs in a written love-potion formula.

### PGM III.71-85
IAO occurs in the spoken conjuration of the cat/angel rite.

### PGM XII.270-350
IAO occurs in the sun-facing consecration invocation.

The exact token therefore survives while deployment changes across directional vocalization, formulaic recitation, and graphic use.

Status:
QUALIFIES STRONGLY.

Caution:
the PGM V instruction specifies direction/manner, not an exact musical pitch or modern frequency.

## F09 — DAMNAMENEU

### PGM III.71-85
DAMNAMENEU occurs in the main conjuration formula.

### PGM III.99-104
The same form recurs in the later solar-boat/Helios stage. Betz's note explicitly says the formula is repeated below at line 100.

### PGM XII.270-350
DAMNAMENEU occurs in the consecration invocation. The rite specifies repeated daily performance and sun-facing execution while holding the stone.

This is particularly useful because PGM III reuses the same token in distinct stages of the same ritual complex.

Status:
QUALIFIES.

## F12 — TWTRWSYAY YHWH / Totrosiay YHWH

### Hekhalot Rabbati 16 / Sefaria witness
The Hebrew text prescribes adjuring Surya 112 times by the name Totrosiay YHWH, explicitly stating that the mouth emits the names while the fingers count 112.

### Hekhalot Rabbati 19
The same written theonym appears on the first-palace seal and is shown to the right-side gate guardians, after which the practitioner is conducted onward.

This is a strong non-PGM same-token/different-modality case.

However, under the frozen TOP-LEVEL v14 function coding both occurrences remain ASCENT_PASSAGE.

Therefore:
- it supports LOCAL EXECUTION/MODALITY BINDING qualitatively;
- it does NOT contribute a function difference to H14-1 or H14-2.

Status:
QUALIFIES AS STAGE/EFFECT CONTRAST, NOT AS TOP-LEVEL FUNCTION CONTRAST.

## Audit conclusion

High-bar direct A/B criterion H14-3 is satisfied by at least:
- F01 Diadem sequence
- F02 ABRASAX
- F04 IAO

Additional qualifying families:
- F06 ABLANATHANALBA
- F09 DAMNAMENEU

F12 supplies an independent non-PGM execution/stage contrast but retains the same primary function label.

This means ancient sources do provide real local cases where the same sacred form is deployed differently for different ritual effects.

The remaining question is whether this local phenomenon generalizes statistically across token families.
