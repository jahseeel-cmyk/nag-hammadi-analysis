# ACCESS-CONTROL TRANSDUCTION MODEL v6 — FROZEN

Freeze date: 2026-09-19

## Origin

v6 is derived from:
- Marsanes / Nag Hammadi training evidence;
- Bruce Codex Untitled Text external replication;
- Pistis Sophia external replication;
- Books of Jeu external replication.

The model is frozen before testing a less-related corpus.

## Core hypothesis

Sacred carriers can function as access-control tokens that mediate movement across ontological or ritual boundaries.

Generic architecture:

IDENTITY / STATE
-> CREDENTIAL / TOKEN
-> VERIFIER / GUARDIAN / GATE
-> RECOGNITION / ACCEPTANCE
-> BOUNDARY STATE CHANGE
-> PASSAGE / REVELATION / ASCENT / TRANSFORMATION

## Carrier classes

A1 SPOKEN:
name, word, formula, invocation, password-like response.

A2 WRITTEN / GRAPHIC:
seal, sign, character, diagram, written name.

A3 WORN / HELD:
garment, token, amulet, object bearing sign/name.

A4 COGNITIVE / RECOGNITION:
knowledge of a name, identity, order, or formula that must be demonstrated.

## Frozen operators

AC1 ISSUE_TOKEN(authority,token)
AC2 PRESENT_TOKEN(subject,token,boundary)
AC3 VERIFY(verifier,token)
AC4 ACCEPT(verifier,subject)
AC5 REJECT(verifier,subject)
AC6 OPEN(boundary)
AC7 WITHDRAW(verifier)
AC8 PASS(subject,boundary)
AC9 ASCEND(subject,state)
AC10 TRANSFORM(subject,state)
AC11 MAP_TOKEN(token,state_or_authority)

## Primary qualifying event

An ACCESS-CONTROL EVENT requires all of:
1. a subject approaching or interacting with a boundary/guardian/verifier;
2. a specific carrier/token;
3. the carrier is presented, uttered, shown, possessed, or demonstrated;
4. the boundary/guardian response changes as a result;
5. passage, protection, recognition, or transition follows.

Mere sacred naming does not qualify.

## Strong replication threshold

At least 2 independent primary access-control events in one corpus, using the frozen operator set, with at least one event involving a specific guardian/gate/boundary response.

## Anti-fitting rules

- no number-only matches;
- no treating generic prayer as authentication;
- no treating every divine name as a password;
- no inferred verifier if the text gives only a blessing;
- no success if the carrier and passage are separated only by modern editorial inference;
- translation-level evidence must be labelled as such.
