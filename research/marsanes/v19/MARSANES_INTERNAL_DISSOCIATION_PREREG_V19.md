# Marsanes Internal Dissociation Search v19 — PREREGISTRATION

Freeze date: 2026-09-21

## Purpose

Discriminate the two tied v18 mechanisms:

H18-A SEMIVOWEL ACTIVATION
versus
H18-B MANY-TO-ONE SOUND UNIFICATION.

The decisive evidence would be an INTERNAL DISSOCIATION CASE in Marsanes.

## Search domain

All surviving text of Marsanes NHC X,1 in:
- project Coptic transcription;
- project English translation;
- critical-edition-backed notes already in the project.

The search is comprehensive across the surviving tractate, not limited to X25–32.

## Target dissociation cases

### D19-A — SEMIVOWEL WITHOUT ONE-SOUND

A qualifying case must contain:
1. explicit semivowel language;
2. an ACTION applied to semivowels:
   summon, call, activate, subject/order, combine, transform, or equivalent;
3. NO explicit one-sound / single-sound / singular sounded-result clause in the same local operation.

Interpretation:
If found with performance vocabulary, SEMIVOWEL ACTIVATION gains priority over MANY->ONE.
If found without performance vocabulary, SEMIVOWEL ACTIVATION alone is insufficient.

### D19-B — ONE-SOUND WITHOUT SEMIVOWEL

A qualifying case must contain:
1. explicit one-sound / single-sound / unified-sound result;
2. NO semivowel referent in the same local operation.

Interpretation:
If found with performance vocabulary, MANY->ONE gains priority over SEMIVOWEL ACTIVATION.
If found without performance vocabulary, MANY->ONE alone is insufficient.

## Secondary controls

### C19-1 — SEMIVOWEL TAXONOMY
Record every explicit semivowel mention that merely classifies semivowels.

### C19-2 — SOUND-UNITY LANGUAGE
Record every occurrence of:
- one sound;
- single sound;
- one voice;
- unified sound;
- equivalent singular acoustic-result language.

### C19-3 — PERFORMANCE VOCABULARY
Record all occurrences of:
- beat/ictus;
- pitch;
- silence;
- hormē/attack/onset;
- explicit equivalent execution terms.

## Window rule

A LOCAL OPERATION is:
- same sentence/clause chain;
or
- continuous operation with no independent subject/topic shift.

Do not link passages separated by:
- major lacuna;
- new grammatical class;
- new cosmological topic;
- unrelated exhortation.

## Frozen decision

1. If D19-A exists and D19-B does not:
   favor SEMIVOWEL ACTIVATION.

2. If D19-B exists and D19-A does not:
   favor MANY->ONE UNIFICATION.

3. If both exist:
   compare performance co-occurrence.
   The mechanism more consistently linked with performance is favored.

4. If neither exists:
   the surviving tractate does NOT dissociate the mechanisms.
   Retain the compound SEMIVOWEL-UNIFICATION operator.

## Anti-fitting

Do not:
- treat taxonomy as activation;
- count metaphorical "voice" as one-sound unless acoustic unity is explicit;
- use restored wording as secure;
- import external PGM/Hekhalot semantics;
- treat simple consonant/vowel combination as many->one unless singular sound-result language is explicit.
