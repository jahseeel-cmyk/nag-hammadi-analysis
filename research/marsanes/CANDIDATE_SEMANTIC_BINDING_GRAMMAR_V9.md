# Candidate v9 — Semantic Binding Grammar

Status: CANDIDATE

## Core claim

The sacred function of a formal operation is not intrinsic to the operation.

Instead:

SACRED FUNCTION = FORMAL OPERATOR + TEXTUAL BINDING.

Define:

BIND(O,F)

where O is a formal operation and F is an explicitly assigned metaphysical/ritual function.

## Marsanes candidate bindings

B1:
BIND(SERIES7(simple vowels), SELF_BEGOTTEN_SOUL)

B2:
BIND(REPEAT3(simple vowels), MALE_THIRD_SOUL_SHAPE)

B3:
BIND(COMBINE(consonant,vowel), DIVINE_ANGELIC_NOMENCLATURE)

B4:
BIND(CHANGE(consonant form) + BEAT/PITCH/SILENCE/IMPULSE, HIDDEN_GOD_SUBMISSION)

## Why BIND matters

Matched school controls can reproduce:
- ordered series;
- triplication;
- vowel/consonant substitution;
- diphthong organization.

They do not reproduce the Marsanes-specific assignment of those forms to soul/divine/ritual functions unless that assignment is added separately.

Therefore the esoteric information, if real, is concentrated in the BIND relation.

## Falsifiers

The model weakens if:
- critical-edition verification removes the local binding relation;
- function assignments depend mainly on restorations;
- comparable school texts make the same metaphysical bindings;
- external transfer requires flexible relabeling of function.

## Research priority

Highest:
verify B1-B4 philologically.

Then:
test whether BIND relation types transfer across independent ritual corpora.
