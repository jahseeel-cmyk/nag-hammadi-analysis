# Marsanes v25 — Marcus → Marsanes Transformation Test

## Research question
What does Marsanes inherit from the second-century Marcosian sound/letter system, what does it transform, and what is newly parameterized?

## Primary-source result

### Shared / inherited structures
Marcus (Irenaeus, Against Heresies I.14; Hippolytus, Refutation VI.37–41) already attests:
- vowel / semivowel / mute taxonomy;
- sacred names decomposed into letters and syllables;
- peculiar pronunciation belonging to each element;
- sound as a formative cosmological power;
- silence as a sacred state;
- a many-to-one restoration model in which elements converge into one letter and one pronunciation / single articulation;
- ritual performance involving prolonged invocation and esoteric utterance.

Therefore these cannot be treated as Marsanes-specific inventions.

### Marsanes transformation
Marsanes retains the older Greek phonological / sacred-letter framework but adds an explicit execution layer:
- beat;
- pitch;
- silence;
- horme / attack / impulse.

This execution bundle is immediately tied to an action:
**the consonants summon the semivowels**, which are then subjected to a **single sound**.

### Decisive distinction
In Marcus, semivowels are cosmological/classificatory: they represent an intermediate ontological class and participate in the alphabetic emanation scheme.

In Marsanes, semivowels become **targets of an operation**.

That is the strongest current transformation:

STATIC CLASS:
semivowels = intermediate sacred letter class

becomes

DYNAMIC CLASS:
execution parameters -> recruit/summon semivowels -> single-sound ordering

## v25 predictions

- P25-A shared taxonomy: PASS
- P25-B many-to-one sound ontology predates Marsanes: PASS
- P25-C four-variable execution bundle absent from surviving Marcus reports: PASS WITH CAUTION
- P25-D active semivowel recruitment is the decisive transformation: CURRENTLY SUPPORTED

Caution: surviving evidence for Marcus is polemical and incomplete; absence in Irenaeus/Hippolytus does not prove absolute historical absence.

## Important correction
Marcus already uses ritual vocal performance, including prolonged invocation. Therefore "special vocal performance" itself must be removed from the novelty claim.

## Revised mechanism

MARCUS:
phonological class
-> sacred letter/name ontology
-> operative pronunciation
-> many-to-one restoration

MARSANES:
phonological class
-> local execution-control bundle
-> active semivowel recruitment
-> single-sound ordering
-> sacred nomenclature

## Strongest current claim
Marsanes appears not to invent sacred phonological cosmology but to **operationalize** it. Its most distinctive surviving mechanism is the conversion of a static Greek phonological class into a dynamically recruited class through named execution variables.

## Falsifier for v26
Find a pre-Marsanes text in which:
1. a phonological class is explicitly acted upon;
2. the action is controlled by named execution parameters;
3. the operation changes the class's functional relation to another class, sacred name, or unified sound state.

If such a source is found, downgrade the Marsanes operator-level novelty claim.
