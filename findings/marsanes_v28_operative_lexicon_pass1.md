# Marsanes v28 — Operative Lexicon, Pass 1

## Decision

The v28 program begins with source discipline rather than maximal comparison.

Several broad similarities are now deliberately downgraded because they are independently attested:
- sacred letter taxonomy;
- letter combination/permutation;
- operative pronunciation;
- pitch/rhythm as technical vocal variables;
- sacred nomenclature;
- many-to-one sound unification.

The highest-information residuals are now:

1. **SEMIVOWEL_RECRUITMENT** — Marsanes' statement that the consonants, by means of beat, pitch, silence and impulse, summon the semivowels, which are subjected to a single sound.
2. **HORMĒ / IMPULSE** — the exact semantic and technical function of ὁρμή in this passage.
3. **LOCAL CAUSAL BINDING** — whether the four execution variables grammatically govern the summoning operation, rather than merely describing surrounding performance.

## Source-backed corrections

The comparison table must not infer primary evidence from later occult practice.

Accordingly:
- Enochian **beat**: NOT ESTABLISHED in the Dee/Kelley primary material used here.
- Enochian **pitch**: NOT ESTABLISHED.
- PGM or Egyptian rhythm/pitch parallels must be entered only when a specific passage is located.
- BAGADAZATHA-type sequences remain phonological/syllabic structures, not proper angel names unless a source explicitly identifies them as such.

## v28 Falsifier

Search for a pre-Marsanes source with the full causal shape:

**execution parameter(s) -> activate/recruit a technical sound class -> change that class's relation to another class, sacred name, or unified sound state**

Loose similarities do not count.

## v28 Priority

The next source audit should concentrate on **ὁρμή**, **καλεῖν**, and **ὑποτάσσειν** in:
- Greek musical/rhythmic theory;
- rhetoric/phonetics;
- grammatical scholia;
- philosophical psychology;
- magical/theurgic literature;
- Gnostic/Valentinian material.

If ὁρμή is ordinary motion/impulse language and not a vocal-performance technical term, the model should treat it as a semantic bridge rather than an acoustic "attack." If a technical vocal use is found, the performance-operator model strengthens substantially.

## Evidence system

All lexicon rows use one of:
- ATTESTED
- RECONSTRUCTED

- ATTESTED_ABSENCE (searched comparator with no secure analogue yet)
